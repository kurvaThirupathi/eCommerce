# ShopMaster — React Frontend Practice Project

This is a frontend-only e-commerce project designed for React interview and real-project practice.

## Run

```bash
npm install
npm run dev
```

Open the URL printed by Vite.

## Implemented

- React + Vite
- React Router
- Redux Toolkit
- Protected routes
- Product listing
- Dynamic product details
- Search
- Debounce
- Category filter
- Price filter
- Sorting
- Pagination
- Product cards
- Wishlist
- Cart
- Cart quantity
- LocalStorage persistence
- Login form
- Form validation
- Multi-step checkout UI
- Orders UI
- Admin dashboard
- Admin search/sort
- Bulk row selection
- Bulk delete
- Responsive CSS
- React.memo
- useMemo
- Custom useDebounce
- Custom useLocalStorage
- 404 page
